# RShare

## Rajagiri Resource & Skill Exchange

**Share. Learn. Borrow. Give Back.**

RShare is a campus-focused platform designed to enable students to share underused resources and skills through a trusted digital exchange system.

### Project Vision

RShare aims to create a campus sharing ecosystem where students can:

- Share underused resources
- Exchange skills
- Borrow items from other students
- Discover useful resources within the campus
- Earn EcoCredits by contributing
- Redeem EcoCredits for campus rewards

### Planned Features

- Student authentication
- Resource sharing
- Skill exchange
- Search and filtering
- Request and approval system
- Borrowing and return management
- EcoCredits
- Campus rewards
- Ratings and reputation
- QR-based handover
- Damage and dispute management
- Late-return management
- Notifications
- Admin dashboard
- Analytics
